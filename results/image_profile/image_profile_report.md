# 이미지 프로필 추천 실험 기록

## 가설

상품 이미지 임베딩만으로 만든 유저 프로필 추천은 구매 이력이 적은 상품(low 판매 빈도, 신상품)에서 ALS보다 hit가 많을 것이다. 전체 지표는 ALS보다 낮을 수 있다.

## 실험

- 유저가 학습 구간에 산 상품의 CLIP 임베딩을 합쳐 프로필을 만들고, 전체 상품(104,798개)과의 코사인 유사도 상위 12개를 추천한다.
- 같은 유저에 대한 ALS 추천과 같은 평가 환경으로 비교한다.
- 이미지 단독 성능을 먼저 알아야 이후 ALS + 이미지 가중합의 변화가 이미지 덕인지 가중치 덕인지 분리할 수 있다.

## 설정

| 항목 | 값 |
|---|---|
| 임베딩 | openai/clip-vit-base-patch32, 512차원, L2 정규화 |
| 프로필 | 구매 0/1로 이진화한 상품 임베딩의 합을 L2 정규화 |
| 후보 | 임베딩 전체 104,798개 (ALS는 학습 행렬의 29,175개) |
| 학습 구간 | train 마지막 4주 (ALS와 동일, `configs/als_best.yaml`) |
| filter_already_purchased | false (ALS와 동일) |
| 평가 | valid, k=12, 커버 유저 (학습 4주에 이력이 있는 유저) |
| 비교군 | 같은 커버 유저로 재평가한 ALS (`als`) |
| 추가 비교 | 이미 산 상품을 뺀 ALS(`als_filter`), 이미지 추천(`image_filter`). 재학습 없이 추천 단계만 다름 |
| 실행 | `python scripts/run_image_profile.py` |

커버 유저 기준이라 전체 유저 표와 값이 다른 것이 정상이다. 미커버 유저는 프로필을 만들 수 없어 이번 비교에서 제외했다.

## 분석

실행 후 아래 항목을 확인한다.

- 이미지 추천의 재구매 비율과 재구매 hit 비중 (이미 산 상품으로 상위를 채웠는지)
- `image`와 `image_filter`의 차이: 산 상품을 빼면 지표가 오르는지 내리는지 (`als`와 `als_filter`의 변화와 비교)
- low 판매 빈도, 신상품 그룹의 recall이 0이 아닌지
- 추천 고유 상품 수 (ALS 665개, BPR 4,969개와 비교)
- 전체 지표 차이가 신상품과 low 판매 빈도 그룹에서만 나타나는지

한계: 임베딩 품질 확인은 type 라벨 기준이라 유저가 실제로 살 상품과 별개다. 이 실험이 처음으로 구매 기준 효과를 본다.
