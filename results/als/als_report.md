# ALS 실험 결과

## 가설
구매 행렬을 유저 벡터와 상품 벡터로 분해하는 ALS가, 규칙 기반 baseline(나이대별 인기 추천,
recall@12 0.0241 / MAP@12 0.0070)보다 개인화된 추천을 제공해 성능을 높일 것이다.

## 실험 1: 시작값 (train_weeks 전체, filter_already_purchased=false)

### 설정
factors 64, regularization 0.01, iterations 15, alpha 1.0, k 12, seed 42
confidence = 1 + alpha × 구매 횟수

### 결과 (valid, 유저 71,952명)

| | age_fallback | ALS |
|---|---|---|
| recall@12 | 0.0241 | 0.0210 |
| MAP@12 | 0.0070 | 0.0090 |
| nDCG@12 | 0.0138 | 0.0147 |

### 분석
recall은 baseline보다 낮고 MAP/nDCG는 높았다. hit를 재구매/신규로 분해한 결과,
ALS 추천의 50.5%가 유저가 train에서 이미 산 상품이었다(재구매 hit 428 → 1,850,
신규 구매 hit 4,185 → 2,165). 재구매는 유저 벡터와 가까워 상위 순위에 오르므로
순위 지표는 오르지만, 신규 적중이 줄어 recall은 떨어졌다.

가설은 부분적으로 기각됐다. 전체 기간 구매 행렬은 오래된 협업 신호를 포함해
과거 재구매 패턴에 치우쳤다.

## 실험 2: filter × train_weeks (8조합)

### 가설
학습 기간을 최근으로 좁히면 최신 트렌드가 반영되어 recall이 개선될 것이다.
이미 산 상품을 추천에서 제외하면(filter=true) 신규 구매 적중이 늘 것이다.

### 결과 (valid, all)

| train_weeks | filter | recall@12 | MAP@12 | 커버율 |
|---|---|---|---|---|
| 전체 | false | 0.0210 | 0.0090 | 92.51% |
| 전체 | true | 0.0128 | 0.0049 | 92.51% |
| 8 | false | 0.0322 | 0.0129 | 62.16% |
| 8 | true | 0.0237 | 0.0085 | 62.16% |
| **4** | **false** | **0.0366** | **0.0147** | 44.98% |
| 4 | true | 0.0265 | 0.0093 | 44.98% |
| 2 | false | 0.0369 | 0.0146 | 31.13% |
| 2 | true | 0.0270 | 0.0092 | 31.13% |
| (age_fallback) | – | 0.0241 | 0.0070 | – |

### 분석
학습 기간을 줄일수록 recall과 MAP가 모두 올랐다. 4주와 2주는 성능이 사실상 같아
(recall 0.0366 vs 0.0369), 커버율이 더 높은 **4주를 최종 설정으로 선택**했다.

filter=true는 모든 기간에서 recall을 25~40% 떨어뜨렸다. 이 데이터는 같은
유저-상품 재구매율이 12.87%로 실제 정답에 포함된 신호이기 때문에, 이미 산
상품을 빼는 가설은 기각하고 filter=false를 유지했다.

## 실험 3: 최종 설정(train_weeks=4, filter=false) 상세 검증

### 커버 / 미커버 분리 (커버율 44.98%)

| 구간 | 유저 수 | age_fallback recall | ALS recall |
|---|---|---|---|
| 커버 | 32,364 | 0.0231 | 0.0510 |
| 미커버 | 39,588 | 0.0248 | 0.0248 (fallback과 동일) |

전체 개선은 전부 최근 4주 안에 구매가 있는 커버 유저(45%)에서 나왔다. 미커버
유저는 age_fallback을 그대로 받으므로 두 값이 같다.

### 그룹별 recall@12

| 그룹 | age_fallback | ALS |
|---|---|---|
| cold | 0.0272 | 0.0335 |
| warm | 0.0235 | 0.0372 |
| 30s | 0.0158 | 0.0309 |
| 40s | 0.0187 | 0.0339 |
| 판매 빈도 low/mid | 0 | 0 |
| 신상품 | 0 | 0 |
| 메타데이터 Unknown | 0.0344 | 0.0402 |

모든 그룹에서 ALS가 앞섰고, baseline에서 가장 약했던 30s/40s 구간의 개선이 가장
컸다. 판매 빈도 low/mid와 신상품은 여전히 0이다. 두 그룹 모두 학습 행렬에
열(상품 벡터)이 없거나 구매 신호가 거의 없어 구조적으로 추천이 불가능하다.
이미지 feature 실험이 검증할 구간은 이 두 그룹이다.

### 재확인 평가 (valid를 한 주 앞당김, week 2)

| | age_fallback | ALS | 변화 |
|---|---|---|---|
| recall@12 | 0.0245 | 0.0346 | +41% |
| MAP@12 | 0.0079 | 0.0136 | +72% |

valid(week 1)에서는 recall +52%, MAP +110%였다. 폭은 줄었지만 모든 지표에서
ALS가 앞서고 커버율도 44~45%로 거의 같아, valid 한 주에만 맞춰진 결과는
아닌 것으로 보인다.

## 결론
- ALS(train_weeks=4, filter_already_purchased=false)를 baseline보다 우수한
  개인화 추천 모델로 확정한다.
- 이 설정을 이미지 feature 실험의 행동 기반 기준 모델로 사용한다.
- 판매 빈도 low/mid, 신상품 구간은 여전히 추천이 0이며, 이것이 이미지 feature
  가설의 핵심 검증 대상이다.

## 한계
- 검증은 valid 한 주와 그 이전 한 주(week 2), 총 두 시점만 확인했다. 통계적
  유의성 검정은 하지 않았다.
- 30s/40s의 큰 개선폭과 메타데이터 Unknown(2,821명)의 결과는 표본이 작거나
  단일 시점 관찰이라 일반화하지 않는다.
- factors, regularization, alpha 등 모델 내부 하이퍼파라미터는 시작값 그대로
  사용했다. 데이터 구성(기간, filter)의 영향이 더 크다고 판단해 추가 튜닝은
  생략했다.
- 온라인 A/B 검증은 하지 않았으며, 오프라인 지표 기준의 결론이다.
