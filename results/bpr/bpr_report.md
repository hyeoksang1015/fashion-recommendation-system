# BPR 실험 기록

## 가설

BPR은 (산 상품, 안 산 상품) 순서를 직접 학습하므로, 같은 조건에서 ALS보다 순위 지표가 높을 것이다.

## 실험

- ALS(최종 설정)와 BPR을 같은 행렬, 같은 평가 조건에서 비교했다.
- 차이가 노이즈인지 확인하기 위해 paired bootstrap과 시드 반복을 추가했다.
- 순위 지표 차이의 원인을 보기 위해 hit 구성과 추천 다양성을 분해했다.

## 설정

| 항목 | 값 |
|---|---|
| 학습 구간 | train 마지막 4주 |
| filter_already_purchased | false |
| 행렬 | 234,750 × 29,175, 비제로 945,026 |
| ALS | factors 64, 나머지 시작값 |
| BPR | factors 64, learning_rate·iterations(100)·regularization은 implicit 기본값, num_threads 1 |
| BPR 입력 | 구매 여부 0/1 (구매 횟수는 반영되지 않음) |
| 평가 | valid, k=12, 유저 71,952명 (커버 32,364명) |
| bootstrap | B=1000, 유저 단위 재추출, 95% 신뢰구간 (백분위수) |
| 시드 | 42, 0, 1 |

학습 시간은 ALS 4.9초, BPR 33.4초다.

## 분석

1. recall은 두 모델을 구별하지 못했다. bootstrap 신뢰구간이 0을 포함하고, 시드별 범위가 겹친다(seed 0에서는 둘 다 0.0367).
2. MAP는 BPR이 높다. bootstrap과 시드 반복 모두 같은 방향이며, BPR의 가장 낮은 시드(0.0161)도 ALS(0.0147)보다 높다.
3. hit 구성이 다르다. BPR은 재구매 hit가 491건 많고 순위도 더 높다. ALS는 신규 구매 hit가 639건 많다. MAP 차이는 재구매 hit의 순위 차이에서 나왔을 가능성이 크지만, MAP를 재구매/신규 기여로 분해하지는 않았다(추론).
4. hit를 얻은 유저 수는 BPR이 157명 적다. 이전 초안의 "hit가 더 많은 유저에게 흩어진다"는 해석은 틀렸으므로 철회한다.
5. BPR은 추천 상품 종류가 7.5배 많다. 이 다양성은 recall 이득으로 이어지지 않았다.
6. mid 판매 빈도 상품은 ALS에서는 추천 자체가 없어 0이었고, BPR에서는 추천되어 0.0099가 나왔다. 따라서 mid는 구조적으로 0인 구간이 아니라 CF 모델에 따라 달라지는 구간이다. low와 신상품은 두 모델 모두 사실상 0이다.

## 결론

- 순위 지표(MAP, nDCG)는 BPR이 높고, recall은 구별되지 않는다.
- 재구매 위주의 순위 정확도는 BPR, 신규 상품 발견 건수는 ALS가 앞선다. 어느 쪽을 우선할지는 평가 목적에 달려 있다.
- 이미지 feature 검증 구간은 low 판매 빈도와 신상품이다. mid는 기준 모델에 따라 귀속 해석이 달라진다(ALS 기준이면 mid에서 생긴 hit를 다른 요인에 귀속하기 쉽다).

## 한계

- 두 모델 모두 튜닝하지 않은 시작값이다. BPR의 learning_rate, iterations, regularization은 implicit 기본값이다.
- bootstrap은 평가 유저 표본의 변동만 반영한다. 학습 무작위성은 시드 3회로 따로 봤지만, 시드 수가 적다.
- 평가는 valid(week 1) 한 주다. ALS는 다른 주로 재확인했으나 BPR은 하지 않았다.
- 4개 비교(전체/커버 × recall/MAP)를 각각 검정했고 다중 비교 보정은 하지 않았다.
- 순위 평균은 hit가 난 건만의 평균이라, 추천 전체의 순위 품질과는 다르다.
- BPR은 num_threads=1로 학습했다. 재현성을 위한 선택이며, 다중 스레드에서는 시드를 고정해도 결과가 달라진다.
